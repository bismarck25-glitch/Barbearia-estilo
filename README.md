 Barbearia-estilo
 sobre o projeto
 site desenvolvido para apresentação de uma barberaria , com foco em design limpo, navegação simples e visual moderno.
 O que foi feito?
 Estruturação completa em HTML5
 Estilização com Css3 -cores , fontes , espaçamentos,
 Layout responsivo , funciona em celular e computador 
 Cabeçalho, seções de conteúdo e rodapé organizados,
 Código identado e bem estuturado com auxilio de IA (inteligência artificial)

Tecnologias usadas 
-HTML5
-CSS3 ,
Para visualizar baixe o arquivo (index.html) e abra no navegador.
----
Projeto desenvolvido como prática de desenvolvimento Web, não adicionei JavaScript , porque inicialmente queria algo visual.
